## Summary of differences

The real production system (shared module + handler together) has:

- **Equal** coverage for HMAC-SHA256 with constant-time comparison, clock-skew
  tolerance, payload-size limit, timestamp validation, missing-signature and
  missing-secret rejection.
- **Better** coverage for replay protection (persistent DB nonces vs. in-process
  tracking that doesn't survive a Function restart) and IP allowlisting (absent
  from the shadow verifier entirely).
- **One shadow-only feature** (`x-payload-hash` header check) that is not
  applicable to real Safaricom callbacks — Daraja does not send this header.
