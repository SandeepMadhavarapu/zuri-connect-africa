# _archive/

This folder contains code removed from the active codebase during
Phase 5 (shadow stack demolition) and later refactors. Code here
is retained for 30-day reference in case any pattern needs revisiting.

**Code in _archive/ is NOT exercised by tests, build, lint, or any
CI gate.** It exists purely as searchable history beyond git.

Files in _archive/ may be safely deleted permanently after the
retention window. Check git log for the original deletion commits.

## Layout
Folders mirror the original src/ tree paths. So a file originally
at src/server/domain/auth/session-service.js lands at
_archive/src/server/domain/auth/session-service.js.
